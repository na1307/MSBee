# MSBee

**MSBee** is a Visual Studio extension/MSBuild SDK that allows you to target **.NET Framework 1.0 and 1.1**. The [original MSBee](https://github.com/na1307/MSBee/tree/original) was written for Visual Studio 2005, but I've reimagined it for modern use.

> ⚠️ Primarily intended for legacy system maintenance or compatibility testing or just fun.

The original MSBee 1.0 can be downloaded from [this link](https://github.com/na1307/MSBee/raw/refs/heads/original/MSBee%201.0%20Release.zip).

## 🧩 How to Build

1. Install **Visual Studio 2026** and **[HeatWave for Visual Studio](https://marketplace.visualstudio.com/items?itemName=FireGiant.FireGiantHeatWaveDev17) extension** (required for building the extension).
2. Clone this repository:
   ```bash
   git clone https://github.com/na1307/MSBee.git
   ```
3. Open the `.slnx` file in Visual Studio.
4. Go to **Build > Build Solution** or press `Ctrl + Shift + B`.
